# Changelog

All notable changes to the **RoadSafetyInsights** (RSI) project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-15

### Added
* **Initial Public Release:** Deployed the core foundational version of the RoadSafetyInsights (RSI) platform.
* **Interactive WebGL Background:** Integrated an optimized 3D background powered by lightweight OGL rendering.
* **Core Landing Page Structure:** Developed fully responsive layouts, feature grids, dynamic stat bars, and dual user-profile interest sections (Drivers vs. Businesses).
* **Serverless Lead Generation:** Integrated Netlify Forms for both driver signups and business demo requests, complete with an invisible **Honeypot spam protection layer** (`bot-field`).
* **GDPR & Legal Compliance:** Added a custom Cookie Consent banner with `localStorage` state management, a dedicated Privacy Policy (`policy.html`), and a GDPR compliance documentation file (`GDPR.md`).
* **Team & Easter Egg Pages:** Created a dedicated Team roster (`team.html`), a custom 404 error page (`404.html`), and a secure developer terminal endpoint (`terminal.html` / `syslog.html`) featuring a dynamic typewriter effect.
* **SEO & PWA Infrastructure:** Configured standard metadata, Open Graph social tags, `robots.txt` with playful ASCII art, `sitemap.xml`, site verification files, and a `site.webmanifest` for Progressive Web App support.
* **Security & Repository Governance:** Established a comprehensive `SECURITY.md` policy outlining supported versions and responsible vulnerability reporting guidelines, alongside robust `.gitignore` and `.gitattributes` configurations.
